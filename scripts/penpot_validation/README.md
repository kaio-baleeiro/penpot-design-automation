# Validação Penpot

Este pacote contém a captura Playwright, medição de documento, derivação de
frame spec, mapa de fontes, comparação de imagens, métricas e gates de estado.

O módulo é chamado pelo CLI em `run.py` e pelos wrappers das skills. Não altere
fórmula, limiares, severidades ou artefatos imutáveis durante uma execução.
