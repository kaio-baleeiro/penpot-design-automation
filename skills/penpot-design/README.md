# penpot-design

Orquestrador do workflow completo. Escolhe `reproduction` ou
`directed_creation`, coordena as skills de fase, delega o trabalho operacional
ao worker econômico do host, aplica os gates e entrega o relatório final.

Leia `SKILL.md` e as referências do contrato antes de iniciar um run. As
lições em `lessons-learned/` são compartilhadas por todas as fases.
