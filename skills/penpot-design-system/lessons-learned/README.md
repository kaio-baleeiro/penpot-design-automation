# Lições do design system

Registre aqui falhas de tokens, estilos, componentes, variantes, instâncias,
detached instances e revalidação estrutural. Regras do projeto ficam em
`project/`; detalhes da máquina ficam em `local/` e não são versionados. A
aparência isolada não prova um design system.

Classifique limitações da máquina como `kind: machine`; regras de estrutura do
produto como `kind: project` e integre-as ao contrato ou aos gates.
