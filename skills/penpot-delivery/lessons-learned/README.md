# Lições da entrega

Registre aqui falhas de pacote, links, aprovações, estado terminal, assets ou
segurança de artefatos. Regras do projeto ficam em `project/`; detalhes da
máquina ficam em `local/` e são ignorados pelo Git. Só entregue quando todos
os gates e aprovações exigidos estiverem persistidos.

Use `kind: machine` para incidentes específicos do ambiente; `kind: project`
para regras de entrega que devem ser integradas à skill, script ou teste.
