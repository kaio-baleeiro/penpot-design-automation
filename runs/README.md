# Runs

Cada execução versionada vive em `runs/<run-id>/`. Manifestos, perguntas,
decisões, mapas sanitizados, planos, scores e relatórios podem ser commitados;
capturas autenticadas, cookies, exports e payloads privados são ignorados.

Consulte `skills/penpot-design/references/artifacts.md` para o contrato dos
artefatos.
