# Delivery package — GitHub Kaio v2

This package records the terminal handoff for the GitHub profile benchmark.
It is a review artifact, not an approval: the state is `NEEDS_REVIEW` after
three validation cycles. The editable Penpot frame, source provenance, cycle
scores and visual comparisons remain linked from the version README and the
manifest in this directory.

Use [`report.md`](report.md) for the human-readable decision and
[`manifest.json`](manifest.json) for machine-readable delivery metadata.

The final evidence is cycle 3. Cycle 1 and cycle 2 are retained to show what
changed and to prevent a future run from hiding regressions. Start any new
improvement as a new version/run; do not mutate a cycle directory.
