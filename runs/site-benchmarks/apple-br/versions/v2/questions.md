# Intake preservado — Apple Brasil v2

As perguntas obrigatórias já foram respondidas na versão anterior e continuam
válidas para este rebuild:

- rota: `reproduction` a partir de URL pública;
- origem prevalente: URL, com captura full-page como evidência visual;
- viewport: desktop `1440×900`; a tela inteira deve acompanhar o documento;
- escopo: tela estática editável, componentes e tokens preliminares;
- assets: autorizado reutilizar SVGs, imagens, ícones, logos e fontes first-party;
- validação: até três ciclos, score mínimo 90, cobertura mínima 80%, sem P0/P1;
- entrega: side-by-side, overlay e heatmap versionados.

Adendo/mudança: o rebuild deve corrigir os achados do ciclo 3, principalmente
hero iPhone Duo, Apple Watch, as três linhas de promos, TV gallery e footer,
usando conteúdo e assets reais em vez de placeholders.
