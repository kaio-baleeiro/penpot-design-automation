# Assets da origem

Inventário de SVGs, imagens, logos, ícones, plataformas e mídia first-party observados na home Warframe. A permissão do benchmark autoriza reutilizar os arquivos exatos encontrados na origem; a aquisição deve ocorrer somente depois da aprovação do boundary e ser registrada no log do build.

O inventário não baixa nem embute os arquivos nesta etapa. URLs completas, hashes e status de aquisição devem ser preenchidos pelo worker durante o build, preservando a proveniência.
