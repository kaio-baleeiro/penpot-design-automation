# Evidências de origem

Contém apenas registros sanitizados e versionados da origem Warframe v2.
`reference-full-page.png` é a cópia pública da captura bounded aprovada em
1440×5837; `capture-metadata.json` preserva as medidas e a decisão sanitizadas.
A captura operacional bruta permanece no armazenamento ignorado em
`source/raw/bounded-1440x5837-v2/`; não copie cookies, tokens, DOM bruto ou
estado autenticado para este diretório.

O mapa mantém a distinção entre viewport, documento observado e frame aprovado.
A altura foi congelada por decisão explícita do usuário; a largura excedente
continua registrada como overflow acidental, sem alargar o frame de 1440 px.
