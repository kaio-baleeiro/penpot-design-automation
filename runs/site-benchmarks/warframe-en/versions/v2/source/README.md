# Evidências de origem

Contém apenas registros sanitizados e versionados da origem Warframe v2. A captura PNG bruta está no armazenamento ignorado em `source/raw/bounded-1440x5837-v2/`; não copie cookies, tokens, DOM bruto ou estado autenticado para este diretório.

O mapa mantém a distinção entre viewport, documento observado e frame proposto. Como a altura foi reproduzida, mas a largura continuou variando, a proposta não é considerada estável nem pronta para pontuação.
