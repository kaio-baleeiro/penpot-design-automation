# Testes

Os testes exercitam contratos de skills, segurança, captura, frame sizing,
mapa de fontes, inventário MCP, transições de estado e validação visual.

Execute na raiz:

```sh
python3 -m unittest discover -s tests -v
```

Um novo aprendizado deve incluir um caso reproduzível aqui antes de ser marcado
como `mitigated` na skill correspondente.
